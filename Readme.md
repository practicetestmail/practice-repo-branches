# 🛠️ Practice Repo for GitHub Branches & Merging

Welcome to **practice-repo-branches**!  
This repository is created to practice **branching, pull requests, and merging** directly on GitHub.  
It’s a hands-on space for learning how to manage branches effectively in 2025.

---

## 📌 What You’ll Learn Here
- How to **create a branch** in GitHub.
- How to **make changes** in a branch.
- How to **open a pull request (PR)**.
- How to **merge a branch** into the main branch.
- How to **delete a branch** after merging.

---

1. **Clone or fork** this repository (if needed).
